## 📌 About The Project

This is a simple **Java Swing GUI Application** developed to understand how event handling works in Java.

The application contains an Exit button. When the user clicks the button, an event is triggered using `ActionListener`, and the application closes.

## ✨ Features

* 🎨 Simple and clean GUI.
* 🔘 Exit button with custom font.
* ⚡ ActionListener event handling.
* 🖥️ Console message when exiting.
* 🚪 Close application using `System.exit(0)`.

## 💻 Code Explanation

| Code                | Description                 |
| ------------------- | --------------------------- |
| `JFrame`            | Creates GUI window          |
| `JButton`           | Creates Exit button         |
| `FlowLayout`        | Arranges components         |
| `ActionListener`    | Handles button events       |
| `actionPerformed()` | Executes button click event |
| `System.exit(0)`    | Terminates application      |

## ▶️ How To Run

1. Clone this repository.
2. Open the project using NetBeans or VS Code.
3. Run `Demo.java`.
4. Click the Exit button.
